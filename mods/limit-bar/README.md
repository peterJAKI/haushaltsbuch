# limit-bar

Balken über dem Eingabefeld: 5-Stunden-Limit mit Prozent und Reset-Uhrzeit.
Grün unter 10 %, ab 70 % gelb, ab 90 % rot.

## Installieren
1. Ordner `limit-bar` nach `~/.claude/mods/limit-bar` kopieren.
2. In `~/.claude/settings.json` eintragen:
   `{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "~/.claude/mods/limit-bar" } }`
3. Claude Code neu starten.
